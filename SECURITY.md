# Security

Please report security problems privately, through GitHub's
**Security → Report a vulnerability** on this repository, rather than in a public
issue. Include what you found, how to reproduce it, and the version (commit) you
tested. You'll get an answer as soon as possible.

Running your own copy: keep Wren up to date, set a strong owner password, turn on
2-step verification or a passkey, and keep each provider's webhook URL secret (it's
what lets mail and delivery events into your instance).
